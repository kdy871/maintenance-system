# 발전소 설비 통합 관리 시스템

이 폴더에는 4개의 개별 웹 애플리케이션이 포함되어 있습니다. 새로 생성된 `index.html` 파일은 이들 앱을 한곳에서 접근할 수 있는 통합 대시보드(포털) 역할을 합니다.

## 사용 방법

1. **`index.html` 실행**: 이 폴더에 있는 `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)에서 엽니다.
2. **시스템 선택**: 통합 화면에서 원하는 관리 시스템 카드를 클릭하면 해당 앱으로 이동합니다.

## 포함된 시스템

1. **Soot Blower 관리** (`/soot-blower-app`)
   - 호기별 Short/Long Blower의 정비 이력 및 현황 관리
2. **EP 설비 관리** (`/tr`)
   - 구역별 모듈 상태 실시간 모니터링
3. **작업지시서 관리대장** (`/작업지시서 관리대장`)
   - 실시간 작업 오더 현황 및 긴급 마감 리스트
4. **브러쉬 교체 현황** (`/브러쉬 교체 현황`)
   - 브러쉬 교체 주기 입력 및 통계 대시보드

## 참고 사항

- 각 시스템은 Google Apps Script와 연동되어 데이터를 불러옵니다. 인터넷 연결이 필요합니다.
- `index.html` 파일은 단순히 각 앱을 연결해주는 링크 역할을 하며, 실제 기능은 각 하위 폴더의 파일들에 있습니다.
